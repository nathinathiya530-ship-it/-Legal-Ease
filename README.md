# -Legal-Ease
AI powered Legal Document generator

### Features
- Generate Rental Agreement, NDA, Employment Contract, Service Agreement in seconds
- Built with Streamlit + Gemini 1.5 Flash
- Download as TXT / DOCX
- Clean, professional legal language

### Tech Stack
- Python, Streamlit
- Google Generative AI (Gemini)
- python-docx

### How to Run
pip install -r requirements.txt
streamlit run app.py
